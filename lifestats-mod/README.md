# 생활 통계 (lifestats) — Minecraft 1.21.8 Fabric 클라이언트 모드

생활 직업(광부/농부/어부/나무꾼/사냥꾼)의 수집량·예상 수익·생직 시간과 버프/재사용 시간을 보여줍니다.
서버 쪽 모드나 접속 제한(화이트리스트) 없이 누구나 쓸 수 있습니다.

## 빌드

1. JDK 21 설치
2. 이 폴더에서 Gradle 래퍼 생성(처음 한 번): `gradle wrapper --gradle-version 8.14`
   (또는 Fabric 예제 템플릿의 `gradlew`, `gradle/` 폴더를 복사)
3. `./gradlew build` → `build/libs/lifestats-1.0.0.jar` 을 `mods` 폴더에 넣기 (Fabric Loader + Fabric API 필요)
4. `gradle.properties` 의 버전 숫자는 https://fabricmc.net/develop 에서 1.21.8 기준으로 확인해 맞추세요.

> 이 소스는 네트워크가 막힌 환경에서 작성돼 **컴파일 검증을 못 했습니다.**
> 빌드 중 오류가 나면 오류 메시지를 알려 주세요. 가장 가능성이 높은 곳은 아래 "API 주의" 항목입니다.

## 사용법

- `K`: 생활 통계 화면 (일간/주간/월간 × 직업 탭, 마우스 휠로 스크롤). 오른쪽 위 "시세 입력"으로 시세 화면 이동
- 키 설정에서 지정: 버프 HUD 켜기/끄기, 경험치 측정 시작점 재설정
- 설정/데이터 폴더: `config/lifestats/`
  - `jobs.json`   직업별 추적 품목 (사냥꾼만 채워져 있음. 다른 직업은 같은 형식으로 추가)
  - `prices.json` 시세 ({"품목명": 개당 가격}). 올려 주신 시세표가 기본값
  - `units.json`  시세 화면에서 고른 단위(1개/1세트/1설커)
  - `buffs.json`  버프 정의 (아이템 이름 매칭, 채팅 정규식 매칭, 효과/재사용 시간)
  - `stats.json`  날짜별 수집 기록 (일/주/월은 이 기록을 합산)

## 동작 방식

- 수집량: 인벤토리를 5틱마다 비교해 `jobs.json` 에 등록된 품목의 증가분을 기록합니다.
  상자·상점 등 화면이 열려 있는 동안은 기준점만 갱신해서 거기서 꺼낸 아이템은 세지 않습니다.
- 품목 이름은 게임 내 표시 이름(색 코드 제거)과 정확히 같아야 합니다.
- 생직 시간: 해당 직업 품목을 얻은 뒤 60초 안이면 활동 시간으로 셉니다.
- 예상 수익 = Σ(수집 개수 × 개당 시세).

## 직접 맞춰야 하는 것

- `buffs.json` 의 시간(효과 35:26, 당비계 08:14/18:14 등)은 시안의 예시값을 그대로 넣은 것입니다. 실제 값으로 고치세요.
  `match` 는 발동 아이템 이름에 들어 있는 글자, `chat` 은 서버가 보내는 메시지 정규식입니다.
- 경험치는 기본으로 바닐라 경험치 바를 읽습니다. 서버가 생활 레벨을 다른 곳으로 알려 주면 `ExpTracker` 의 current* 만 바꾸면 됩니다.
  시안의 "획득 경험치"는 레벨 곡선이 필요해 아직 넣지 않았습니다.
- 시세표에 없는 품목(대부분의 부산물)은 0원으로 시작합니다. 시세 입력 화면에서 채우세요.

## API 주의 (1.21.8 기준)

- `HudRenderCallback` 은 Fabric API 최신 버전에서 deprecated 지만 1.21.8 에서는 동작합니다.
- `KeyBinding` 카테고리는 문자열입니다. 1.21.9 이상으로 올리면 `KeyBinding.Category` 로 바뀝니다.
- 화면 마우스 입력은 `mouseScrolled(double, double, double, double)` 형태입니다. 1.21.9 이상에서는 시그니처가 달라집니다.
